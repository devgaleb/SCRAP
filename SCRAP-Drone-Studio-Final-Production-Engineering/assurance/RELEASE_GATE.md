# Release gate

1. Freeze aircraft configuration, controller hardware, firmware hash and parameter set.
2. Identify operating environment, jurisdiction, operation category and approval references.
3. Complete hazard analysis and trace every safety requirement to independent evidence.
4. Run software, integration, SITL and HIL tests with documented results.
5. Perform authorised controlled ground and flight testing by qualified personnel.
6. Conduct cybersecurity and penetration assessments, verify secrets management, TLS and network isolation.
7. Obtain independent safety review and any required aviation authorisations.
8. Sign an accountable release decision and document operating limitations.

No automated readiness report grants certification or permission to fly.
